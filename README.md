# Russian Roulette Game

## 📌 Overview
This is a high-stakes betting game where if you lose, it can delete Windows system files or other files you specify. The game works by having you guess a number - if your chosen number matches the system's random pick, you lose and files get deleted.

**⚠️ Extreme Warning:** This program can cause irreversible damage to your system. Use at absolute own risk. Created for educational purposes only.

---

## 🎮 How It Works
1. You select a number range (e.g., 1 to 10)
2. You guess a number in that range
3. System generates a random number
4. If numbers match:
   - Critical files get deleted (including Windows system files if specified)
5. If numbers don't match, you win safely

---

## 🌟 Features
- Dangerous file deletion capability
- System modification permissions
- Windows/Linux compatible
- Android version works with Pydroid/Termux
- Colorful terminal interface
- Game result logging system
